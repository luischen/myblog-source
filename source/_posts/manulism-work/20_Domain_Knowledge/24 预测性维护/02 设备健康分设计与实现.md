# 设备健康指数：从诊断结果到退化趋势

{% note info %}
**核心思路**
设备健康指数（Health Index，HI）将多个诊断信号转换到统一刻度，合成为设备状态，并沿时间轴观察变化。它帮助人判断**现在哪里值得关注、哪些信号支撑这一判断、退化是否持续**。
{% endnote %}

## 为什么需要健康指数

预测性维护往往同时使用规则、统计方法和机器学习模型。一个模型输出正常或异常，另一个输出偏离程度，第三个输出连续数值。这些结果的量纲和含义不同，无法直接放在同一张设备列表中比较。

单次报警也只回答“这一刻是否触发条件”。健康指数补上连续视角：先统一表达各诊断结果，再汇总成设备状态，最后通过趋势判断变化方向。设计时应始终保留原始诊断结果，避免一个总分掩盖局部异常。

{% mermaid %}
flowchart LR
    A[传感器与业务数据] --> B[规则或模型诊断]
    B --> C[各诊断因子评分]
    C --> D[设备健康指数]
    D --> E[因子贡献与详情]
    D --> F[时间趋势]
    F --> G[阈值到达时间估计]
{% endmermaid %}

## 设计的三个层次

### 诊断因子：明确“分数代表什么”

一个诊断因子应对应一个可解释的设备状态信号，例如轴承振动异常、温升偏离或某个模型的诊断结果。它需要有稳定的标识、时间戳、原始值、诊断结论和评分所依据的阈值或规则版本。

这里的因子是**诊断层的结果**，不必等同于模型输入的每个特征。若把输入特征直接作为健康因子，容易重复计算高度相关的信息，也难以解释它与实际故障模式的关系。

### 因子评分：统一刻度，但尊重模型语义

可将因子状态映射到 0～100 分，100 表示健康基准，分数越低表示偏离越明显。不同诊断类型需要不同映射方式：

| 诊断输出 | 评分思路 |
| --- | --- |
| 正常 / 异常等离散结果 | 根据诊断结论映射分数；不要用单点数值替代包含连续点、趋势等条件的规则判断。 |
| 有效上下阈值的连续结果 | 以正常区间中心为基准，根据与中心的距离及区间半宽计算偏离程度。 |
| 只有上阈值且“越大越异常”的结果 | 以健康基准值为起点，按诊断值相对上阈值的比例计算偏离。 |

**离散诊断示例。**某振动规则综合最近 5 个观测点给出“正常”或“异常”结论。即使最后一个观测值尚未越过单点阈值，连续上升也可能使规则判为异常。若采用“正常 = 100 分、异常 = 60 分”的示例映射，这次结果应记为 **60 分**；规则判为正常时记为 **100 分**。评分依据是规则结论，不能只拿最后一个观测值重新判断。

一种便于解释的**示例映射**是令异常边界对应 60 分：

<script type="math/tex; mode=display">
s_i=\operatorname{round}_{0.1}\!\left(\operatorname{clamp}(100-40d_i,\ 0,\ 100)\right)
</script>

其中 <script type="math/tex">d_i</script> 是归一化偏离程度，边界处 <script type="math/tex">d_i=1</script>。这个 60 分只是示例刻度，不是通用行业标准；实际映射应依据故障机理、历史样本和现场容忍度校准。缺失或非法阈值、无法解析的时间、非有限数值应明确排除，并暴露数据质量问题。

**连续诊断示例。**某无量纲诊断指标的正常区间为 10～30，中心为 20，半宽为 10，因此 <script type="math/tex">d=|x-20|/10</script>。按上式计算：当 <script type="math/tex">x=25</script> 时，<script type="math/tex">d=0.5</script>，得到 **80 分**；当 <script type="math/tex">x=30</script> 时，达到边界，得到 **60 分**；当 <script type="math/tex">x=45</script> 时，<script type="math/tex">d=2.5</script>，分数截断为 **0 分**。连续值保留了偏离程度，而不只是正常或异常两档。

### 设备聚合：总分与解释一起输出

设参与计算的因子分数为 <script type="math/tex">s_i(t)</script>，其有效权重为 <script type="math/tex">w_i</script>，设备健康指数可写为：

<script type="math/tex; mode=display">
HI(t)=\operatorname{round}_{0.1}\!\left(\frac{\sum_i s_i(t)w_i}{\sum_i w_i}\right)
</script>

权重表达业务重要性和诊断可靠性，可按故障模式、设备类型或模型类别设置。若一类模型关联多个诊断项，可先将该类权重分配给各项，再对当期有有效结果的项归一化。**缺失结果不能直接算作 0 分**，同时应展示有效因子数或覆盖率，避免数据稀少时出现看似可靠的高分。

例如三个因子分数分别为 100、60、80，相对权重为 10、45、45，则总分为 <script type="math/tex">100\times10\\%+60\times45\\%+80\times45\\%=73</script>。展示总分时，也应展示每个因子的分数及贡献。贡献分四舍五入后可分配余量，保证展示值之和与总分一致。

{% note warning %}
**贡献不等于归因**
因子贡献度说明它占当前总分的数值比例，并不表示它导致故障的概率或责任比例。根因判断仍需结合原始数据、诊断详情和现场检查。
{% endnote %}

## 从健康分到退化趋势

设备状态由多个异步更新的因子组成。构建趋势时，可以按业务时区生成日末快照：每个因子取当天最后一次有效诊断；当天未更新的因子沿用最近有效值；没有任何因子更新的日期不补点。这样既避免把缺测误判为退化，也避免人为制造观测数据。

趋势窗口、因子状态的最长沿用时间和最少有效点数都应配置。若某个因子长时间不更新，应标出其数据新鲜度，必要时让总分进入“数据不足”状态，而不是持续显示旧分数。

在有效日点足够时，可用线性拟合估算健康分变化斜率。若斜率持续为负，拟合线与业务参考阈值的交点可作为**安排复核的时间线索**。阈值需要按设备和场景校准；预测结果应与样本点数、时间窗口及拟合方式一同展示。

{% note danger %}
**线性外推的边界**
阈值到达时间不是剩余寿命的确定结论。工况变化、维修、模型漂移或短期噪声都会改变走势。点数不足、斜率非负或数据陈旧时，应显示“无法推算”，而不是给出貌似精确的日期。
{% endnote %}

## 它对预测性维护有什么帮助

| 运维问题 | 健康指数提供的线索 |
| --- | --- |
| 先看哪台设备？ | 用同一刻度筛查设备，同时核对数据新鲜度与因子覆盖率。 |
| 为什么这台设备的分数下降？ | 从总分回到因子贡献、原始诊断和阈值，定位需要复核的信号。 |
| 是一次波动还是持续退化？ | 比较日末点、拟合斜率与工况变化，识别持续下降。 |
| 何时安排检查？ | 参考阈值时间帮助排序检查计划，最终决定仍由风险、生产安排和现场证据共同支持。 |

健康指数的价值是**让诊断结果可比较、让变化可追踪、让干预有依据**。它适合作为人工研判和维保优先级的输入；自动报警或工单动作应另行定义触发条件、复核机制与误报处理。

## 实施时要守住的边界

- **时间与版本**：保存评分所用的诊断结果、阈值和规则版本，保证历史数据可复核。
- **缺失与陈旧**：分别说明无结果、无效结果和长时间未更新，不能默认为健康。
- **权重治理**：记录权重变更；若新权重重算历史曲线，应明确提示口径改变。
- **验证方式**：用已知正常、退化和故障样本检查分数排序，也检查不同设备和工况下的误报、漏报。
- **展示方式**：总分、因子详情、最近更新时间和趋势一起呈现，避免只给一个数字。

{% note success %}
**设计原则**
健康指数先要**可解释且可复核**，再追求预测能力。若评分无法回到诊断证据，精致的趋势图也难以支撑真实的维保决策。
{% endnote %}
